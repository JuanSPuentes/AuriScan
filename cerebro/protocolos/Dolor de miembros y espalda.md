# Dolor de miembros y de espalda (§9.2 y §9.3)

Regla general: **área corporal correspondiente + [[Shen Men]] + [[Punto Cero]] + [[Punto Talamo]]**. Si la respuesta es limitada, añadir puntos de Fase II y III y descartar cicatrices tóxicas / focos dentales (ver [[Fases de Nogier]], [[Impedimentos para el exito del tratamiento]]).

| Cuadro | Principales (además de área + maestros) |
|---|---|
| Fractura ósea | Riñón `.C`, Glándula Suprarrenal `.C`, Glándula Paratiroides |
| Luxación / inflamación articular | [[Punto Endocrino]], Riñón `.C`, Glándula Suprarrenal `.C`; compl. [[Punto Alergia]], Ápice de la Oreja, Ápice del Trago, Omega 2, Hélix 1-6, Prostaglandinas 1 y 2 |
| Atrofia / parálisis motora | Motoneuronas espinales, Corteza Frontal, Cerebelo, Bazo `.C`, Glándula Paratiroides |
| Espasmos / calambres musculares | Relajación Muscular, [[Punto Talamo]] |
| Esguinces / lesión deportiva | punto Calor, Glándula Suprarrenal `.C`, Hígado, Bazo `.C`, Riñón `.C` |
| Neuralgia periférica | Neuronas sensitivas espinales; compl. Cerebro, Cadena Simpática, Glándula Suprarrenal `.C`, [[Punto Maestro Sensorial]] |
| Dolor de hombro / bursitis | Hombro (+ Fase II), Maestro del Hombro, Clavícula, Columna Cervical y Dorsal; compl. Relajación Muscular, n. Occipital Menor |
| Codo de tenista | Codo (Fases I-III), Antebrazo, Brazo, Columna Dorsal, Occipucio |
| Túnel carpiano / dolor de muñeca | Muñeca (Fases I-III), Antebrazo, Mano, Columna Dorsal |
| **Dolor de espalda** | Columna Dorsal + Lumbosacra, Nalgas, n. Ciático, Lumbago (+ Fase II sobre cresta de la concha, Fase III sobre el trago); compl. punto Darwin, Relajación Muscular, Hígado, Vejiga, Glándula Suprarrenal `.C` |
| **Fibromialgia** | Columna Dorsal + Lumbosacra, Relajación Muscular, Antidepresivo, Psicosomático 1, [[Punto Talamo]]; compl. Cadena Simpática, [[Punto Maestro Oscilacion]], Vitalidad, [[Punto Tranquilizador]] |
| Neuralgia intercostal | Tórax, Columna Dorsal, Médula Espinal Dorsal |
| Artrosis / osteoporosis | Glándula Paratiroides, Paratirotrofina; compl. [[Punto Endocrino]], Glándula Suprarrenal, ACTH, Omega 2, [[Punto Alergia]] |
| **Artritis reumatoidea** | Omega 2, Prostaglandinas 1 y 2, [[Punto Alergia]], Glándula Suprarrenal `.C`, [[Punto Endocrino]]; compl. [[Punto Maestro Oscilacion]], Riñón `.C`, Bazo `.C`, San Jiao, Hélix 1-6 |
| **Ciática** | n. Ciático, Nalgas, Lumbago, Columna Lumbar, Cadera, Muslo, Pantorrilla, Glándula Suprarrenal `.C`, Riñón `.C`, Vejiga |
| Dolor abdominal / pélvico | Abdomen, Pelvis, n. Vago, [[Punto Autonomo Simpatico]] |
| Anestesia quirúrgica | Tórax, Abdomen, Estómago, Pulmón 1 y 2, Occipucio, Genitales Externos `.C` |
