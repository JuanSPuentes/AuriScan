# Trastornos urinarios y de órganos abdominales (§9.16 y §9.17)

## Urinarios (§9.16)
Base: **Vejiga + Riñón `.C`/`.E` + Uretra `.C`/`.E` + [[Shen Men]] + Occipucio**.

| Cuadro | Añadir |
|---|---|
| Antidiurético / desequilibrio hídrico | San Jiao, Pituitaria Posterior, [[Punto Cero]], [[Shen Men]], [[Punto Autonomo Simpatico]], Corazón `.C`, Bazo `.C`/`.E`, Glándula Suprarrenal `.C`/`.E` |
| Enuresis | Occipucio, Excitación, [[Shen Men]], compl. [[Punto Talamo]], Cerebro, n. Hipogástrico, Bazo `.C`, Hígado, San Jiao |
| **Cálculos renales** | Uréter `.C`/`.E`, [[Punto Cero]], [[Shen Men]], [[Punto Autonomo Simpatico]], [[Punto Talamo]] |
| Nefritis | punto Nefritis, Occipucio, [[Punto Endocrino]], [[Punto Autonomo Simpatico]], Glándula Suprarrenal `.C`/`.E`, Bazo `.C`, Hígado |
| **Infección urinaria / cistitis** | Uretra `.C`/`.E`, Uréter `.C`/`.E`, [[Shen Men]], Occipucio; compl. [[Punto Cero]], [[Punto Autonomo Simpatico]], Glándula Suprarrenal `.C`/`.E` |
| Incontinencia / retención | Uréter `.C`/`.E`, [[Punto Endocrino]], Genitales Externos `.C`/`.E`, San Jiao |
