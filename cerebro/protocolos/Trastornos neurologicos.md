# Trastornos neurológicos (§9.6)

| **Déficit de atención / hiperactividad (TDAH)** | Hipocampo, Núcleo Amígdala, Tirotrofina, Glándula Tiroides `.C`/`.E`, [[Shen Men]], Shen Men Posterior, [[Punto Maestro Oscilacion]]; compl. [[Punto Maestro Cerebral]], [[Punto Cero]], Riñón `.C`, Cerebro, Tronco Encefálico, Occipucio |

| Epilepsia / convulsiones | Núcleo Amígdala, Corteza Temporal, Frente, Cerebro, Tronco Encefálico, Occipucio, Corazón `.C`, Bazo `.C`; compl. [[Punto Cero]], [[Shen Men]], [[Punto Talamo]], [[Punto Maestro Oscilacion]], Estómago, Hígado, n. Occipital Menor |

| Meningitis | Tronco Encefálico, [[Punto Cero]], [[Shen Men]], [[Punto Talamo]], Occipucio, Frente, Riñón `.C`, Estómago, Corazón `.C`, n. Occipital Menor, Glándula del Timo, Vitalidad |
| Esclerosis múltiple | área corporal + Tronco Encefálico, Médula Oblonga, [[Punto Maestro Oscilacion]], [[Punto Cero]], [[Shen Men]], [[Punto Talamo]], Occipucio, Glándula del Timo, Vitalidad |
| Temblores parkinsonianos | Tegmento del cerebro medio, Estriado, Glándula Suprarrenal `.C`, ACTH, [[Punto Cero]], [[Shen Men]] |
| ACV / apoplejía | área cerebral correspondiente, Cerebro, Glándula Suprarrenal `.C`/`.E`, ACTH, [[Shen Men]], [[Punto Autonomo Simpatico]], [[Punto Maestro Cerebral]], [[Punto Endocrino]] |
| Polio / pospolio | área corporal + Motoneuronas espinales, Médula Oblonga, [[Punto Maestro Cerebral]], [[Punto Cero]], [[Shen Men]], [[Punto Endocrino]] |
