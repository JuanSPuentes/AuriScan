# Trastornos gastrointestinales (§9.15)

Base digestiva: **el/los órgano(s) implicado(s) + [[Punto Autonomo Simpatico]] + [[Punto Cero]] + [[Shen Men]]**. El [[Punto Autonomo Simpatico|Autónomo Simpático]] es clave en casi todo dolor visceral.

| Cuadro | Principales |
|---|---|
| Distensión abdominal | Estómago, Intestino Delgado, Intestino Grueso, Abdomen, Cintura Pélvica, Ascitis; compl. Plexo Solar, San Jiao |
| Colitis / enteritis | Intestino Delgado y Grueso, Estómago, [[Punto Cero]], [[Shen Men]], [[Punto Autonomo Simpatico]]; compl. Recto `.C`, Bazo `.C`, Occipucio |
| **Estreñimiento** | punto Estreñimiento, Intestino Grueso, Recto `.C`/`.E`, Omega 1, Abdomen; compl. [[Punto Talamo]], San Jiao, Estómago, Bazo `.C` |
| **Diarrea** | Intestino Delgado y Grueso, [[Punto Cero]], [[Shen Men]], [[Punto Autonomo Simpatico]]; compl. Recto, Omega 1, Bazo `.C`, Riñón `.C`, Occipucio |
| Colon irritable | Intestino Delgado y Grueso, Recto `.C`/`.E`, Abdomen, Omega 1, Estreñimiento, Estómago; compl. [[Punto Autonomo Simpatico]], Páncreas, Occipucio, San Jiao |
| **Gastritis / espasmos gástricos** | Estómago, Abdomen, [[Punto Cero]], [[Shen Men]], [[Punto Autonomo Simpatico]], Bazo `.C`; compl. Intestino Grueso, Hígado, Pulmón 1 y 2, n. Occipital Menor |
| Hemorroides | Hemorroides `.C1` y `.C2`, Recto `.C`/`.E`, Intestino Grueso, Bazo `.C`, [[Punto Talamo]], [[Punto Cero]], [[Shen Men]], Glándula Suprarrenal `.C` |
| Indigestión | Estómago, Cardias, Intestino Delgado, [[Punto Autonomo Simpatico]], Páncreas, Bazo `.C`, [[Shen Men]], [[Punto Cero]], Omega 1, Hígado, Occipucio |
| **Náuseas / vómitos** | Estómago, Esófago, Omega 1, [[Punto Cero]], [[Shen Men]], [[Punto Autonomo Simpatico]], [[Punto Talamo]], Occipucio |
| Úlcera gástrica / duodenal | Estómago, Duodeno, Intestino Delgado, Abdomen, [[Shen Men]], [[Punto Autonomo Simpatico]], [[Punto Cero]]; compl. Psicosomático 1, [[Punto Talamo]], [[Punto Maestro Cerebral]], Occipucio |
