# Correspondencias somatotópicas de las regiones auriculares

**Tabla maestra**: qué órgano / sistema representa cada región. La IA la usa para pasar de «signo visible en la zona X» a «hipótesis en el sistema Y». Un punto reflejo activo solo aparece cuando hay patología, dolor o disfunción en la región corporal correspondiente (ver [[Puntos auriculares reactivos]]).

## Cara anterior (superficie visible)

| Región | Representa |
|---|---|
| [[Helix]] | Punto antiinflamatorio; alergias y neuralgias |
| Raíz del hélix | Genitales externos, trastornos sexuales, disfunciones urogenitales, diafragma |
| Hélix superior | Alergias, artritis, procesos inflamatorios |
| Cola del hélix | Asta dorsal, neuronas sensitivas medulares, simpático preganglionar; neuropatías periféricas y neuralgias |
| [[Helix interno]] | Órganos genitales internos, riñones, alergias |
| [[Antihelix]] | Sistema musculoesquelético: tronco y torso |
| Raíz superior del antihélix | Miembros inferiores (pierna y pie) |
| Raíz inferior del antihélix | Columna lumbosacra, nalgas, ciática, lumbalgia |
| Cuerpo del antihélix | Columna dorsal; tórax, abdomen; dolor de la parte superior de la espalda |
| Cola del antihélix | Columna cervical, músculos de la garganta, dolor cervical |
| [[Lobulo]] | Corteza cerebral, sensibilidad facial, analgesia ocular/mandibular/dental; **reflejos condicionados, resistencias psicológicas, bloqueos emocionales** |
| [[Trago]] | Cuerpo calloso, control del apetito, glándulas suprarrenales |
| [[Antitrago]] | Cráneo, cabeza; cefaleas frontales, temporales y occipitales |
| [[Cisura intertragica]] | Glándula pituitaria, control de las glándulas endocrinas, trastornos hormonales |
| [[Fosa escafoidea]] | Extremidades superiores: hombro, brazo, codo, muñeca, mano, dedos |
| [[Fosa triangular]] | Extremidades inferiores: cadera, rodilla, tobillo, pie; **útero y órganos pelvianos** |
| [[Concha]] | Enfermedades de los órganos |
| Concha superior | Órganos abdominales: bazo, páncreas, riñón, vejiga |
| Concha inferior | Órganos torácicos: corazón y pulmones; abuso de sustancias |
| Cresta de la concha | Estómago e hígado |
| Pared de la concha | **Tálamo, cerebro, nervios simpáticos, circulación vascular, control general del dolor** |
| [[Subtrago]] | Problemas de lateralidad, nervio auditivo, región interna de nariz y garganta |

## Cara posterior (aspecto motor)

| Región | Representa |
|---|---|
| Cara posterior de la oreja | Aspecto **motor**: espasmos musculares, parálisis motoras |
| Lóbulo posterior | Corteza motora, sistema extrapiramidal, sistema límbico |
| Surco posterior | Control motor de espasmos de músculos paravertebrales |
| Triángulo posterior | Control motor del movimiento de la pierna, espasmos y debilidad motora |
| Concha posterior | Control motor de órganos internos |
| Periferia posterior | Neuronas motoras medulares, control motor de brazo y mano |

Nota (§3.8): los puntos reflejos del borde periférico del hélix se hallan a ~30° de la línea que une [[Puntos de referencia auriculares|PR 0]] con el punto de la patología.
