# Hélix

Cresta circular más externa de la aurícula; borde cartilaginoso plegado, con forma de signo de pregunta.

## Subregiones
- **Raíz del hélix**: segmento inicial, asciende desde el centro hacia la cara. Representa genitales externos, trastornos sexuales, disfunciones urogenitales, diafragma. Aloja [[Punto Cero]] (en PR 0).
- **Hélix superior**: sección más alta, gran arco. Alergias, artritis, procesos inflamatorios. Aloja [[Punto Alergia]] (ápice, PR 2).
- **Cola del hélix**: región final, desciende vertical por la zona periférica. Asta dorsal, neuronas sensitivas medulares, simpático preganglionar; neuropatías periféricas y neuralgias. De PR 4 a PR 5 = médula espinal.
- **Tubérculo de Darwin**: abultamiento del hélix externo entre PR 3 y PR 4.

## Lectura visual
Eritema/relieve en hélix -> punto antiinflamatorio, alergias, neuralgias. Ver [[Correspondencias somatotopicas de las regiones]].
