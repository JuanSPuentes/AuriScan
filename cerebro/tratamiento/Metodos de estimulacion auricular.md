# Métodos de estimulación auricular

Contexto para interpretar **qué se ve en la foto** (agujas, semillas, tachuelas) y para describir el tratamiento aplicado.

## Métodos (§6.1–6.7)

| Método | Descripción |
|---|---|
| **Acupresión** | masaje general (calmante) + masaje específico con palpador metálico de bolita sobre los puntos reactivos |
| **Punción con aguja** | agujas filiformes finas insertadas en el punto |
| **Electroacupuntura (EAE)** | corriente sobre las agujas |
| **Estimulación transcutánea (ETA)** | electrodos de superficie, sin aguja |
| **Semillas / bolitas** (vaccaria, esferas iónicas, perlas) | pegadas con cinta; se dejan **≤ 1 semana**; el paciente presiona varias veces al día. Tan efectivas como agujas, menos riesgo de infección |
| **Magnetos** | imanes pegados con cinta |
| **Agujas de presión / tachuelas semipermanentes** | se dejan varios días; estímulo más fuerte que las semillas |
| **Pistola / inyector** | frecuente en tratamientos de peso (puntos Estómago, Esófago) |
| **Acupuntura acuosa** | inyección subcutánea (novocaína, salino, vitaminas, hierbas) |

## Tonificación vs dispersión (§6.9)

| | Tonificación | Dispersión |
|---|---|---|
| Objetivo | activar funciones débiles (déficit / energía baja) | reducir sobreactividad / exceso de energía por estrés o tensión |
| Polaridad eléctrica | **positiva**, 6–10 s | **negativa**, 12–30 s (hasta varios minutos) |
| Aguja (auriculopuntura) | **oro**, rotación horaria, activa simpático | **plata**, rotación antihoraria, activa parasimpático |
| Indica | dolor que **mejora** con el reposo → aguja de oro | dolor que **empeora** con el movimiento/ejercicio → aguja de plata |

## Siete zonas de frecuencia (§6.6, Cuadro 6.1)

Frecuencias de resonancia por territorio tisular (naranja/A 2,5 Hz subtrago … púrpura/G 160 Hz lóbulo medial); crecen con la complejidad evolutiva del tejido. Relevante para la **estimulación**, no para el diagnóstico visual.

## Lectura en la foto

Si la imagen muestra **agujas, semillas o tachuelas**, identificar su **posición → punto** (modo «con agujas») y describir el método aparente. Si muestra **eritema post-tratamiento generalizado**, es el efecto adverso temporal esperado (ver [[Precauciones y contraindicaciones]]).
