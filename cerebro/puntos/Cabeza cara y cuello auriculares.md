# Cabeza, cara y cuello auriculares (§7.2.4)

Puntos muy frecuentes en protocolos de cefalea, ATM, tortícolis, odontalgia y trastornos psíquicos. El **cráneo** se proyecta sobre el [[Antitrago|antitrago]]; los **músculos de la cara**, sobre el [[Lobulo|lóbulo]].

## Cráneo → antitrago (dividido en tercios)

| Punto | Zona | Uso |
|---|---|---|
| **Occipucio** | AT3 (tercio externo/superior), PR 12–13 | cefalea occipital, mareo, relajación, casi universal |
| **Sienes** (Temporal) | AT2 (tercio medio), PR 13 | migraña, asma, cefalea temporal |
| **Frente** (Frontal) | AT1 (tercio inferior/medial), PR 12 | cefalea frontal, sinusitis, insomnio, ansiedad |

Chino y europeo coinciden en la ubicación de la cabeza.

## Cara y boca → lóbulo

| Punto | Zona | Uso |
|---|---|---|
| Cara (Mejillas) | LO3 / LP5 | espasmos faciales, tics, neuralgia del trigémino, parálisis facial, acné |
| Mandíbula superior / inferior | LO7–LO8 | ATM, odontalgia |
| ATM | LO8 | bruxismo, disfunción temporomandibular |
| Dientes (Odontalgia 1/2/3) | LO1–LO2 · PC3 · CI5 | odontalgias |
| Analgesia Dental 1 / 2 | LO2 / LO1 | analgesia para procedimientos dentales |
| Paladar 1 / 2 | LO4 | úlceras e infecciones de encías |
| Lengua | LO4 (chino) / LO5 (europeo) | dolor y sangrado lingual |
| Labios | LO3 / LP5 | herpes labial |
| Nariz Interna / Externa | subtrago / trago | rinitis, sinusitis |
