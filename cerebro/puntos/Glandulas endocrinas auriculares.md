# Glándulas endocrinas auriculares (§7.4)

Núcleo del [[Eje neuroendocrino]]. Dos agrupaciones: **craneales** (control central, en la cisura intertrágica y el trago) y **periféricas** (glándulas diana, sobre la pared de la concha).

## Glándulas craneales → [[Cisura intertragica]] + trago (§7.4.2)

Representan las hormonas tróficas del **eje hipotálamo-hipofisario**.

| Punto | Zona | Función |
|---|---|---|
| [[Punto Endocrino]] / Pituitaria | IT2 | glándula maestra; lleva las hormonas a la homeostasis |
| Pituitaria Anterior | IT / cisura | ACTH, TSH, FSH/LH, GH, endorfinas |
| Pituitaria Posterior | IT / cisura | ADH (líquidos), oxitocina (parto) |
| ACTH | IT (europeo, cerca PR 9) | respuesta al estrés, cortisol |
| Tirotrofina (TSH) | IT | estimula tiroides |
| Gonadotrofina (FSH/LH) | IT | gónadas |
| Prolactina | IT | lactancia |
| Paratirotrofina | IT | calcio, excitabilidad nerviosa |
| **Glándula Pineal** | TG1 (europeo) | melatonina, sueño, ritmo circadiano; **déficit ↔ depresión** |
| Hipotálamo | pared concha, cerca Tálamo | ver [[Sistema nervioso auricular]] |

## Glándulas periféricas → pared de la concha + trago (§7.4.1)

| Punto | Zona | Función |
|---|---|---|
| **Glándula Suprarrenal (chino)** | TG3 (protrusión inferior del trago, PR 10) | hormonas adrenocorticales, **lucha contra el estrés**; antiinflamatorio, antialérgico; usado casi como punto maestro |
| Glándula Suprarrenal (europeo) | PC7 (pared concha, bajo PR 16) | corteza suprarrenal |
| **Cortisol 1 / 2 / 3** | FE2·AH9 / CS6 / — (por fases de Nogier) | corticoesteroide para superar el estrés |
| Glándula Tiroides | AH8 (chino) / PC4–5 (europeo) | metabolismo; hipo → letargo y depresión; hiper → nerviosismo (Graves) |
| Glándula Timo | PC6 (europeo) | inmunidad (T-helper, natural killers); VIH, cáncer, autoinmunes |
| Glándula Mamaria | senos / AH zona | lactancia |
| Glándula Páncreas | CS7 | insulina/glucagón; diabetes |
| Ovario / Testículo (endocrino) | PC1 (chino) / HI1 (europeo, Fase I) / CI2 (Fase II) / LO2 (Fase III) | disfunción sexual, ovaritis, frigidez |
| Paratiroides | AH8 zona | calcio |

## Lectura visual

Hiperemia focal del **trago** y la **cisura intertrágica** → reactividad endocrina/suprarrenal → sugiere hiperactividad del eje HPA (cortisol elevado). Ver [[Manchas de coloracion oscura]] y [[Distres y tension]].
