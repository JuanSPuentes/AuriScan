# Órganos internos auriculares (§7.3)

Los órganos se representan sobre la **[[Concha|concha]]** (valle central), siguiendo el patrón del feto invertido. La medicina china es más detallada aquí que la europea.

## Sistema digestivo → cresta de la concha + concha superior

Rodean la cresta de la concha (prolongación de la raíz del hélix) en el orden del tubo digestivo:

| Órgano | Zona | | Órgano | Zona |
|---|---|---|---|---|
| Boca | CI6 | | Intestino Delgado | CS2 |
| Esófago | CI7 | | Intestino Grueso | CS3 |
| Estómago | CC1 | | Apéndice | CS3 zona |
| Duodeno | CS1 | | Recto | HX3 (raíz hélix) |
| Hígado | CC2 | | Vesícula Biliar | CS zona (chino) |
| Páncreas | CS7 | | Bazo | CI8 (chino) / CS8 (europeo) |

## Órganos torácicos → concha inferior

| Órgano | Zona | Uso |
|---|---|---|
| **Corazón** | CI4 (chino) | palpitaciones, angina; en MTCH **calma la mente, la memoria, el nerviosismo** → [[Eje neuro-psicologico]] |
| Pulmón 1 / Pulmón 2 | CI4–CI5 | asma, tos, piel, **desintoxicación de drogas** |
| Bronquios / Tráquea | CI3 | broncoespasmo |
| Diafragma | HX2 (chino) / CI (europeo) | hipo, sangrado |
| Tonsila (amígdala) 1–4 | HX + LO periféricos | amigdalitis |

## Órganos abdominales → concha superior

Riñón, Vejiga, Uréter, Próstata (chino) sobre la concha superior, bajo la raíz inferior del antihélix.

## Órganos urogenitales

| Estructura | Zona chino | Zona europeo |
|---|---|---|
| Riñón | CS6 | HI5–6 (hélix interno) |
| Vejiga | CS5 | CS5 |
| Útero | FT6 | HI3 |
| Ovario / Testículo | — | HI1 |
| Próstata / Vagina | CS4 | HI2 |
| Genitales externos | HX4 (raíz hélix) | HX1 zona |

> [!warning] Precaución
> La estimulación fuerte de **Útero** y **Ovario** puede inducir aborto en el embarazo (ver [[Precauciones y contraindicaciones]]).

## Lectura visual

Estómago/duodeno **blancos y abultados** = gastritis crónica; **rojo fuerte** = agudo. Vesícula biliar **rojo oscuro** en el 81% de las patologías (ver [[Manchas de coloracion oscura]]). Concha con eritema difuso → activación parasimpática.
