# Sistema nervioso auricular (§7.5)

Representado sobre todo en **hélix y lóbulo**, pero distribuido por todo el pabellón. Es el sustrato de los ejes [[Eje neuro-psicologico|neuro-psicológico]] y [[Eje sensorial|sensorial]].

## Médula espinal → cola del [[Helix|hélix]] (§7.5.3)

De PR 4 a PR 5. Cara anterior = neuronas **sensitivas**; cara posterior = neuronas **motoras**.

| Segmento | Zona | Nota |
|---|---|---|
| Lumbosacra | HX12 / PP8 | bajo el tubérculo de Darwin, PR 4 |
| Dorsal | HX13 / PP6 | periférico a la cresta de la concha |
| Cervical | HX14 / PP4 | sobre PR 5 |

## Tronco encefálico → pared de la concha + cola del hélix

| Punto | Zona | Función |
|---|---|---|
| Tronco Encefálico (chino, Médula Oblonga) | PC4, bajo PR 14 | temperatura, respiración, ritmo cardíaco; tonifica el cerebro, detiene convulsiones, reduce fiebre |
| Médula Oblonga (europeo) | HX15 / PP2 | idem |
| Protuberancia | LO7 / LP6 | sueño REM, sueños; **insomnio, pesadillas, mareo, reacciones psicosomáticas** |
| Cerebelo | AH1 / LP4 | coordinación, tono postural, temblor intencional, vértigo, **depresión clínica** |
| Techo del cerebro medio | LO6 | reflejos visuales y auditivos |
| Tegmento del cerebro medio | LO5 / LP5 | metabolismo básico, dolor; temblores parkinsonianos, tortícolis, calambre del escritor |
| Formación Reticular | LO8 / ST3 | activación, atención, alerta, vigilancia, lateralidad |

## Núcleos subcorticales → antitrago, pared de la concha, lóbulo (§7.5.4)

| Núcleo | Función clave para el reporte |
|---|---|
| Hipotálamo Anterior | **sedación general** (parasimpático) |
| Hipotálamo Posterior | **activación simpática, conducta agresiva** |
| Sistema Límbico | emociones y memoria |
| Hipocampo | **atención, memoria de largo plazo, experiencias emocionales** |
| Núcleo Amígdala | **agresividad, irritabilidad, manía** (Agresividad 1 = LO2 está sobre esta zona) |
| Núcleo Accumbens | control dopaminérgico de la recompensa; **adicciones** (alcohol, opioides, cocaína, metanfetaminas) |
| Estriado | movimientos semivoluntarios (extrapiramidal) |

## Corteza cerebral → [[Lobulo|lóbulo]] (§7.5.5)

| Área | Zona | Función |
|---|---|---|
| Corteza Prefrontal (= [[Punto Maestro Cerebral]]) | LO1 / LP1 | **toma de decisiones; concentración deficiente, obsesiones, preocupación** |
| Corteza Frontal (motora piramidal) | LO3 / LP3 | inicia la acción motora; parálisis, tono muscular |
| Corteza Parietal (somatosensitiva) | LO5–LO6 | **parestesias táctiles, dolor musculoesquelético**, ACV somestésico |
| Corteza Occipital (visual) | AT3 / LO8 | **trastornos visuales neurológicos**, ceguera, distorsiones |
| Corteza Temporal (auditiva) | LO6 / LO8 | **trastornos auditivos, sordera, discriminación de tonos** |
| Bulbo Olfatorio | LO2 | olfato |
| Cuerpo Calloso | TG1–TG5 (todo el trago) | **lateralidad cerebral** (ver [[Trastornos de lateralidad y oscilacion]]) |

## Nervios periféricos y autónomos (§7.5.1–7.5.2)

| Nervio / estructura | Zona | Uso en protocolos |
|---|---|---|
| **Nervio Occipital Menor** (= Corriente de Aire) | HI10, unión hélix interno / fosa escafoidea | cefalea, neuralgia, alergias, "viento patógeno" |
| Nervio Trigémino | LO5 / LO7 / LP5 | neuralgia facial, odontalgia, ATM |
| Nervio Facial | LP (posterior), LO zona | parálisis de Bell, espasmo facial |
| **Nervio Vago** | CI (concha inferior), zona pared | activación parasimpática, ansiedad, GI, tos |
| Nervio Óptico | LO periférico | visión |
| Nervio Auditivo | subtrago / LP | tinnitus, sordera |
| Cadena Simpática | a lo largo de la pared de la concha | activación autonómica excesiva, hipertensión |
| Ganglios Cervicales (sup/medio/inf) | pared concha / borde antihélix | dolor regional, autonómico |
| Plexo Solar (= [[Punto Cero]]) | HX1 / raíz hélix | "cerebro autónomo" de los órganos |
| Plexo Hipogástrico | raíz hélix / concha sup | pelvis, autonómico |

## Lectura visual

Lóbulo congestivo → corteza/límbico reactivo (estrés, ansiedad). Eritema difuso en concha → nervio vago / parasimpático. Prominencia de la cola del antihélix → cervical. Ver [[Observacion visual de la piel auricular]].
